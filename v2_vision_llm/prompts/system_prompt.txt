- Dates are often written loosely (e.g., "16 avril 1974", "mars 78"). Always convert them to YYYY-MM-DD. If only month and year are given, use the 1st of the month (YYYY-MM-01). If a date is missing or illegible, output "Unknown".

   Addresses (Civic number and Street name) are often written once near the top or bottom, or next to a specific job. If an address is written anywhere on the card, apply that address to ALL valid jobs on the card, even if the address itself was written next to a job that was skipped (e.g., a 1999 job).

4. LOT NUMBER PROPAGATION:
   If a single lot number is written at the top, apply it to all jobs. 
   If there are multiple lots (e.g., "Lots 47-39 et 47-40") and multiple jobs (e.g., "Piquetage, Implantation"), you MUST cross-multiply. For 2 lots and 2 jobs, you must output 4 JSON objects.

5. TOP-LEFT NUMBERS:
   The Minute, No Dossier, and No Mandat fields should generally all be filled with the large number often found in the top-left corner or associated with the surveyor's seal/minute (e.g., 10882).
